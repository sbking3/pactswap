SECURITY REQUIREMENTS

1. EMAIL VERIFICATION: Send 6-digit OTP via nodemailer on signup. Expires 10min
2. 2FA: Google Authenticator with speakeasy + qrcode
3. SIWE: Verify wallet signature before POST
4. Rate limit: 5 requests per 10 seconds
5. Helmet.js security headers
6. Zod validation
7. Admin: wallet == ADMIN_WALLET
8. Encrypt bank details
9. KYC: 3 levels. Level 1: Email. Level 2: BVN. Level 3: ID + Selfie

KEY UI LOGIC

1. SIGNUP: Wallet + Email + Name -> Send EmailOTP -> Verify -> Create User
2. LOGIN: Connect Wallet + Sign Message + 2FA if enabled
3. CREATE OFFER: Must KYC Level 1+. Encrypt bank
4. CREATE ESCROW: USDT.approve -> createEscrow -> status=0
5. BUYER PAID: "I Have Paid on PACTSWAP" -> status=1
6. SELLER CONFIRM: "Confirm Payment Received" -> releaseEscrow() -> status=2
7. DISPUTE: "Open PACTSWAP Dispute" -> status=4
8. BOT: Every 1hr call processExpiredEscrows()
9. SHARE PROFILE: WhatsApp, Facebook, Copy Link
